# Explore Noakhali

A premium, account-free tourism website for Noakhali, Bangladesh.

## Included
- Home / destination discovery
- Destination detail pages
- OpenStreetMap map embed
- Guest trip planner with localStorage
- Budget calculator
- Food explorer
- Culture & heritage
- Guest quiz
- Explore challenge
- Photo gallery placeholders
- SEO metadata
- No authentication
- No Supabase
- No required API keys

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push this folder to GitHub, then import the repository into Vercel. Vercel detects Next.js automatically.

## Important content rule

Some destination facts and coordinates are intentionally marked as unverified. Replace them only after local/authoritative verification. Do not publish invented travel times, prices, coordinates, opening hours or claims.
